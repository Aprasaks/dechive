# DECHIVE

AI를 이해하고 다루는 데 필요한 지식을 배우고, 확인하고, 자신의 언어로 다시 설명해 축적하는 공개 지식 저장소입니다.

현재 저장소는 2026년 9월 전면 재구축 중입니다.

## 기술 기준

- Next.js App Router
- TypeScript
- Supabase Postgres, Auth, Storage
- TipTap editor
- Vercel deployment
